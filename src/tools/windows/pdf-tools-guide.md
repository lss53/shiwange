## 工具概览

| 工具 | 类型 | 定位 | 资源占用 | 价格 |
|:-----|:-----|:-----|:--------:|:-----|
| **福昕 PDF** | 阅读器+编辑器 | 国产首选，功能全面 | 中等 | 免费/付费 |
| **PDF-XChange** | 阅读器+编辑器 | 轻量高效，注释强大 | 低 | 免费/付费 |
| **Adobe Acrobat** | 阅读器+编辑器 | 行业标准，功能最全 | 高 | 付费 |
| **SumatraPDF** | 纯阅读器 | 极简轻量，速度最快 | 极低 | 免费开源 |

## 选型对比

| 需求 | 推荐工具 |
|:-----|:---------|
| **阅读 PDF、EPUB、MOBI、DjVu、CBZ** | SumatraPDF（极速） |
| **重注释/批注** | PDF-XChange（注释最强） |
| **PDF 编辑/转换** | 福昕付费版 / Adobe Acrobat |
| **行业标准/全功能** | Adobe Acrobat |
| **国产/中文优先** | 福昕 PDF |
| **开源/极简主义** | SumatraPDF（苏门答腊） |
| **低配电脑** | SumatraPDF / PDF-XChange |
